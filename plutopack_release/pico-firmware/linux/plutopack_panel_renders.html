PlutoPack · front-panel display bring-up

The serial demo, on the panel

The same gauge, encoder, button and touch readout the Pico prints over USB serial — now rendered on the 320×240 ILI9341 front panel, refreshed live from Linux on the PlutoSky.

Picosensors + UI → SPI → Zynq / Linuxpolls status frame → fbtft → /dev/fb0ILI9341 320×240

Pixel-accurate. Each image is the native 320×240 framebuffer output, shown at 2× with nearest-neighbour scaling. They are produced by the same C renderer (pp_screen.h, IBM VGA 8×8 font) that draws /dev/fb0 on the target — so this preview is what the panel shows, not an impression of it.
